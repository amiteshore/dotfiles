# Dotfiles

Personal macOS dotfiles and configurations.

## Quick Start

Run the installation script:

```bash
./install.sh
```

## Included Tools & Configs

- **Shell**: Zsh, [Starship](https://starship.rs/) prompt, completions, plugins, aliases, and functions
- **Node**: [fnm](https://github.com/Schniz/fnm) (Fast Node Manager) + pnpm
- **Terminal**: [Kitty](https://sw.kovidgoyal.net/kitty/) & [tmux](https://github.com/tmux/tmux) (with TPM)
- **Editor**: Vim & [Antigravity IDE](https://antigravity.google) (with settings and MCP servers)
- **CLI Utilities**: `fzf`, `zoxide`, `bat`, `eza`, `ripgrep`, `fd`, `jq`, `gh`
